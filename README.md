# JLPT Word of the Day

Android widget-first JLPT vocabulary app. The home screen widget shows a daily word for the selected JLPT levels, including kanji, hiragana, katakana, romaji pronunciation, part of speech, meaning, and an example sentence.

## Data Sources

The bundled vocabulary seed is a compact offline set intended for widget use. It is sourced from freely reusable public Japanese dictionary and example-sentence projects:

- JMdict/EDICT for Japanese headwords, readings, English glosses, and part-of-speech metadata: https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project
- Tanaka Corpus for Japanese-English example sentence material: https://www.edrdg.org/wiki/Tanaka_Corpus.html
- Tatoeba for reusable Japanese-English sentence pairs: https://tatoeba.org/en/downloads
